# Microsoft 365 Admin Center Administration Lab

## Lab Overview

A hands-on lab covering the core administrative tasks performed in the Microsoft 365 Admin Center. This lab covers creating and managing user accounts, creating Microsoft 365 Groups and Security Groups, configuring Multi-Factor Authentication (MFA), resetting user passwords, disabling and blocking user accounts, and assigning administrative roles to users.

## Environment

- **Platform:** Microsoft 365 Admin Center
- **Tenant:** `sudeep45479.onmicrosoft.com`

## Topics Covered

- Microsoft 365 Admin Center navigation
- Creating and managing user accounts
- Creating Microsoft 365 Groups and Security Groups
- Configuring Multi-Factor Authentication (MFA)
- Resetting user passwords
- Disabling and blocking user accounts
- Assigning administrative roles

## What Was Done

- Navigated the M365 Admin Center dashboard and reviewed the Active Users list
- Created new user accounts through the **Add a user** wizard, including `Tom support` (`tom@sudeep45479gmail.onmicrosoft.com`, job title "Operating Events") and `neem stir` (`neem@sudeep45479gmail.onmicrosoft.com`, job title "Team Lead", department "Program Organiser"), each with an auto-generated password and no product license assigned
- Created a Microsoft 365 Group, **IT Support Help** (`itsupporthelp@sudeep45479.onmicrosoft.com`), set to Public privacy, with owner `admin` and members `admin`, `John support`, and `Tom support`
- Configured Multi-Factor Authentication (MFA) for user accounts
- Reset a user's password from the Active Users panel
- Blocked sign-in access for user `neem stir`, confirming the account would be signed out of all Microsoft services within 60 minutes, then unblocked the account and verified the user could sign in again
- Assigned administrative roles to users via the **Manage roles** panel — for example, granting `John support` the **Helpdesk Administrator** role (with other available roles such as AI Administrator, Exchange Administrator, Global Administrator, Global Reader, Service Support Administrator, SharePoint Administrator, and User Administrator visible in the same panel)

## Conclusion

Successfully demonstrated practical administration of the Microsoft 365 Admin Center, including user lifecycle management, group management, multi-factor authentication, password administration, and role-based access control — core skills for IT Help Desk and Junior System Administrator roles working with Microsoft 365 environments.
